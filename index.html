ریزالورهایی که تونل DNS شما واقعاً از آن‌ها کار می‌کند

The DNS resolvers your DNS tunnel really works through

در قطعی اینترنت معمولاً فقط DNS باز است. DNS Tunnel Scanner روی همان اینترنتی که هستید (همراه اول، ایرانسل، مخابرات…) ریزالورها را یکی‌یکی با خود کلاینت تونل و ترافیک واقعی تست می‌کند و فقط آن‌هایی را که واقعاً کار می‌کنند، مرتب‌شده بر اساس سرعت، تحویل می‌دهد؛ با لینک و QR برای بقیه.

During a shutdown often only DNS is left. DNS Tunnel Scanner tests resolvers one by one on the network you are on (MCI, Irancell, TCI…) with the real tunnel client and real traffic, and hands you only the ones that really work, fastest first, with a link and a QR code for everyone else.

چطور کار می‌کند

How it works

«جواب می‌دهد» کافی نیست؛ ریزالور فقط وقتی «سالم» است که یک اتصال واقعی تونل از آن ترافیک واقعی رد کند.

"It answers" is not enough: a resolver counts only when a real tunnel session through it carried real traffic.

⚡

۱. فیلتر سریع

1. Quick filter

یک نام تصادفی زیر دامنه‌ی تونل شما پرسیده می‌شود. فقط سرور تونل شما می‌تواند جوابش را بدهد، پس جواب یعنی ریزالور به سرور می‌رسد. هزاران ریزالور در دقیقه.

A random name under your tunnel domain is asked. Only your tunnel server can answer it, so an answer proves the resolver reaches the server. Thousands of resolvers a minute.

🔌

۲. تست واقعی

2. Real test

خود کلاینت StormDNS فقط با همان یک ریزالور اجرا می‌شود، اتصال می‌سازد و یک صفحه‌ی HTTPS از داخل تونل باز می‌کند. اگر نشد، یک بار دیگر امتحان می‌شود تا یک بسته‌ی گم‌شده ریزالور سالم را رد نکند.

The real StormDNS client starts with just that one resolver, builds a session and loads an HTTPS page through the tunnel. A failure gets a second try, so one lost packet doesn't reject a good resolver.

📶

۳. سرعت و رتبه

3. Speed and ranking

از هر ریزالور سالم یک دانلود کوچک رد می‌شود؛ نتیجه بر اساس سرعت مرتب می‌شود، با زمان پاسخ و MTU.

A small download goes through each working resolver; results are ranked by speed, with reply time and MTU.

🔗

۴. اشتراک

4. Share

لیست ریزالورها و لینک پروفایل WhiteDNS را کپی کنید یا QR آن را به بقیه‌ی هم‌اپراتوری‌ها نشان دهید.

Copy the resolver list and the WhiteDNS profile link, or show its QR code to others on the same ISP.

امکانات

Features

ریزالورهای خودِ دستگاه

The device's own DNS

DNS اپراتور (یا مودم) خودکار پیدا و تست می‌شود؛ معمولاً همین‌ها در قطعی باز می‌مانند.

The ISP's (or router's) DNS is found and tested automatically: these usually stay open in a shutdown.

لیست‌های آماده + رنج دلخواه

Built-in lists + your ranges

ریزالورهای عمومی ایرانی و خارجی، به‌علاوه‌ی IP یا رنج CIDR دلخواه شما (تا 65536 آدرس).

Iranian and global public resolvers, plus any IPs or CIDR ranges you add (up to 65536 addresses).

پیدا کردن همسایه‌ها

Find neighbours

وقتی ریزالوری کار کرد، بقیه‌ی /24 آن هم تست می‌شود؛ ریزالورهای اپراتورها کنار هم هستند.

When a resolver works, the rest of its /24 is tested too: ISP resolver farms sit together.

حافظه برای هر شبکه

Memory per network

ریزالورهای سالم برای هر اپراتور جدا ذخیره و دفعه‌ی بعد اول تست می‌شوند، حتی وقتی اینترنت جهانی قطع است.

Working resolvers are remembered per ISP and tested first next time, even when the global internet is down.

مراقب سرور شما

Gentle on your server

هر اتصال تستی بعد از تست درست بسته می‌شود تا جای کاربران واقعی سرور را نگیرد.

Every test session is closed properly afterwards, so it never takes a slot from the server's real users.

دو زبانه، تاریک، موبایل

Bilingual, dark, mobile

فارسی و انگلیسی، روی گوشی و کامپیوتر؛ نسخه‌های جدید را خودش خبر می‌دهد.

Persian and English, on phone and PC; tells you when a new version is out.

FAQ

به پنل یا سرور دسترسی لازم دارد؟

Does it need panel or server access?

نه. همان لینک پروفایلی که در WhiteDNS وارد می‌کنید کافی است و فقط روی دستگاه خودتان می‌ماند.

No. The same profile link you import into WhiteDNS is enough, and it stays on your own device.

چرا نتیجه روی اپراتور دیگر فرق دارد؟

Why do results differ per ISP?

هر اپراتور ریزالورهای خودش را دارد و فیلترینگ هم فرق می‌کند. روی هر سیم‌کارت / وای‌فای جدا اسکن کنید؛ برنامه برای هر شبکه جدا یادش می‌ماند.

Each ISP has its own resolvers and filtering. Scan on each SIM / Wi-Fi; the app remembers each network separately.

«بسته‌ها کوچک (MTU)» یعنی چه؟

What does "packets too small (MTU)" mean?

ریزالور به سرور می‌رسد ولی جواب‌های بزرگ DNS را که تونل لازم دارد رد نمی‌کند؛ با این ریزالور تونل کار نمی‌کند.

The resolver reaches the server but drops the large DNS replies the tunnel needs, so the tunnel can't work through it.
